# 🎓 Student Class Program (Python)

A simple Python program demonstrating the basics of **Object-Oriented Programming (OOP)** using a `Student` class.

This project shows how to create a class, define attributes, create methods, and access object data.

## 📌 About The Project

The program creates a `Student` object with basic details such as:

- Student name
- Age
- Qualification
- Address

It also contains simple actions performed by the student like eating and studying.

## ✨ Features

✅ Create a Student class  
✅ Initialize student details using constructor  
✅ Store object attributes  
✅ Display student information  
✅ Perform actions using methods  

## 🛠️ Technologies Used

- Python 3.x
